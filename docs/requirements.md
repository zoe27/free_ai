# 免费 AI API 聚合网关 — 需求文档

## 1. 背景与目标

个人日常使用大模型（写代码、聊天助手、脚本调用）时，直接按官方定价调用成本较高。目标是搭建一个**自建的统一 API 网关**，聚合多个免费的大模型来源，以低成本（理想情况下完全免费）满足个人日常使用需求。

## 2. 核心需求

| 项 | 要求 |
|---|---|
| 使用场景 | 个人日常调用（脚本、工具、聊天助手），非对外服务 |
| 成本目标 | 优先完全 0 成本；本地模型作为可选扩展 |
| 模型来源 | 多个免费来源聚合，越多越好 |
| 接口格式 | OpenAI 兼容接口（`/v1/chat/completions`），便于现有工具/SDK 直接替换 base_url 接入 |
| 技术栈 | Python |
| 访问范围 | 其他设备也可用（具体部署方式：本地跑 or 云端托管，暂不确定，留作后续选择） |

## 3. 非目标 / 待定项

- 部署方式（本地 + 内网穿透 vs 云端免费托管）暂不确定，先跑通本地版本，后续再选
- 不做面向公众的服务，不考虑多用户/鉴权体系（个人使用为主）
- 灰色/违反 ToS 的逆向 API 方案不采用

## 4. 已知可用的免费模型来源

### 4.1 海外厂商官方免费额度
| 来源 | 说明 |
|---|---|
| Google Gemini API | 个人开发者免费层较宽松，Flash 系列 |
| Groq | 免费调用 Llama3.x / Mixtral / Gemma / Qwen，速度极快 |
| Cerebras | 免费跑开源模型，速度快 |
| Mistral (La Plateforme) | 部分模型有免费额度 |
| Cohere | 免费试用 key，有限流 |
| HuggingFace Inference API | 免费层，限流较严 |
| Together AI | 注册常送免费额度 |
| Cloudflare Workers AI | 每日免费 quota |
| NVIDIA NIM | 免费 API 目录，限流 |
| GitHub Models | GitHub 账号免费用，含多种模型（限流） |

### 4.2 聚合平台（含免费模型）
| 来源 | 说明 |
|---|---|
| OpenRouter | 部分模型带 `:free` 标签，直接免费调用（限流） |
| SiliconFlow（硅基流动） | 国内聚合平台，部分开源模型免费 |

### 4.3 国内厂商
| 来源 | 说明 |
|---|---|
| DeepSeek | 价格很低，偶有免费额度 |
| 智谱 GLM | 新用户免费额度 |
| Moonshot Kimi | 免费额度 |
| 阿里通义千问 (Qwen) | 免费额度 |
| 百川 | 免费额度 |
| 讯飞星火 | 免费额度 |

### 4.4 本地运行（真 0 成本，占本地算力，扩展项）
| 来源 | 说明 |
|---|---|
| Ollama | 最主流，一键跑 Llama / Qwen / Mistral / Gemma / DeepSeek-R1 蒸馏版 |
| LM Studio | GUI + 本地 API server |
| vLLM | 有 GPU 时性能更强 |
| llama.cpp | 底层引擎，轻量 |

### 4.5 不建议采用
- 第三方对 Poe / 其他产品的"逆向 API 封装"——违反 ToS、稳定性差，不接入

## 5. 待确认事项（下一步需要拍板）

1. 首批接入的模型来源优先级（例如：Gemini + Groq + OpenRouter 免费模型 + 本地 Ollama）
2. 网关的路由策略：固定优先级 fallback？按额度/限流自动切换？手动指定？
3. 部署方式：本地常驻 + 内网穿透，还是云端免费托管
4. 各来源 API Key 的管理方式（本地 `.env`，是否需要额度/限流监控）
